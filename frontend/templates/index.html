Como funciona?

Este CRM integra com a Evolution API (gratuita e open-source). Siga os passos:

  1. Instale a Evolution API no seu servidor ou computador
  2. Informe a URL e chave da API abaixo
  3. Escaneie o QR Code que aparecerá com o seu WhatsApp

Documentação da Evolution API

Escanear QR Code

Abra o WhatsApp no seu celular → Dispositivos conectados → Conectar dispositivo

O QR Code expira em 60 segundos. Após escanear, clique em "Verificar conexão".
