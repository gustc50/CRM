E-mail do sistema

Conta usada para o sistema falar com os clientes: boas-vindas, confirmação de pagamento e aviso de vencimento. É separada do e-mail que cada cliente configura para mandar documentos ao contador dele. Sem isto preenchido, nenhum aviso é enviado — o resto do sistema funciona normalmente.
